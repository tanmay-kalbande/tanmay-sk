1. Pehla Show: Domain aur Hosting ka Khel

Online duniya mein apna empire banana chahta hai? Pehli condition: apna khata khud khol. Par bina pata huye bhaagta hua agar hosting pe paise udayega, toh baad mein rona manega. Pehla Show: Domain aur Hosting ka Khel Plot Kya Hai, Bhai? Address aur Zameen ka Farq Sun, 90% log is game mein isliye phaste hain kyunki inko domain aur hosting ka funda clear nahi hota. Inka dimaag kachra ho jata hai. Main ekdum seedha bata deta hoon, taaki tu kabhi bhatke nahi. Soch, tu dukaan kholne ja raha hai. Domain Name teri dukaan ka address hai—jaise "Chandu Chaiwala, Gali No. 4". Log is address ko search karke teri dukaan tak pahunchenge. Hosting teri dukaan ki asli zameen (plot) aur chhat (space) hai. Jahan tu apna samaan, furniture, aur board rakh sakta hai. Agar tere paas sirf address hai (domain) par zameen nahi hai (hosting), toh log address pe aayenge aur khali plot dekh ke wapas chale jayenge. Bekaar! Aur agar zameen hai par pata nahi, toh koi tujhe dhoond hi nahi payega. Dono ek doosre ke bina bekar hain. Are you getting this? Takeaway: Domain = Address jo log yaad rakhte hain. Hosting = Zameen jahan teri website akele mein nahi aati, balki rehti hai. Naam Soch, Zubaan Pe Chokha Lage Apne business ke liye domain name choose karna pehli date jaisi feeling deta hai. Exciting hai, par log isme bhi bakchodi karte hain. 20 letter ka domain le lenge, jaise best-cheap-quality-mumbai-vada-pav-online.com. Bhai, koi yaad nahi rakhega itna lamba naam. Typing karte karte ungli thak jayegi. Aisa naam chun jo chhota, catchy aur seedha dimaag mein ghus jaye. vadapavwala.com ya mumbaichow.com chal jayega. Kuch rules yaad rakh: - .com pe focus kar: India mein .in bhi chal jaata hai, par duniya bhar mein .com ki alag hi aukaat hai. Agar .com nahi mil raha, toh thoda naam change karke dekh, par .com chhodna mat jab tak zaroorat na ho. - Numbers aur hyphens ( - ) se door reh: pizza2night.com ya cool-pizza.com lagta hai koi spam site chala raha hai. Professional nahi lagta. - Trademark check karle: Agar tu googlevadapav.com le raha hai, toh kal ko legal notice padega. Apna original naam soch. Takeaway: Naam aisa ho jo subah 5 baje neend mein bhi koi type kar de. Lamba kheencha toh game bigad gaya. Hosting Kharidne ka Khel: Raddi Mat Utha Ab aate hain plot pe. Tu Google pe "best hosting" search karega aur tere samne 100 ads aayenge—Hostinger, Bluehost, GoDaddy, SiteGround. Har koi bolega "mera sabse sasta, sabse fast". Beginner ke liye sirf ek hi rule hai: Shared Hosting se shuru kar. Shared hosting matlab ek hi server (computer) pe teri website ke alawa 50 aur websites chal rahi …

2. WordPress Install: Engine Start Karle Bhai

Pehle chapter mein tune zameen (hosting) aur address (domain) fix kar liya. Ab khali plot pe chhat dalni hai ya nahi? Server pe WordPress ka engine daale bina teri website ek khaali plot hi reh jayegi jahan koi aake nanga naach nahi dekhne wala. Chal, sleeve up kar aur hat-kade baith. Aaj system ka aakaar khud se baithayenge. cPanel Ka Darwaza Tod, WordPress Ka Engine Joda Shared hosting liya hai? SSL laga diya? Badiya. Ab tera server ekdum ready hai. Direct WordPress.org se files download karke FTP se upload karne ki zaroorat nahi hai. Coder banne ki nautanki chhod. Aaj kal har hosting company—Hostinger, Bluehost, ya jo bhi tune pakda hai—ek "1-click install" deta hai. Yeh aisa feature hai jaise microwave mein ready-to-eat packet daal ke timer lagana. Bas button dabaya, aur 2 minute mein khana taiyaar. Apne hosting ke control panel (cPanel ya hPanel) mein ghus. Wahan tujhe ek section milega jiska naam hoga "Auto Installers" ya "Website" ya phir "WordPress Manager". Isko locate karne mein apne dimag ki batti nahi jalaani, screen padhni hai. Us option pe click kar. Ek form aayega. Is form ko aise bharna hai jaise passport application bhar raha hai—ek haddi galat hui toh bhatak jayega. Form Ke Khaas Hisse 1. Domain Select Kar: Yahan tera khud ka domain naam likhne ka option hoga jo tune pehle chapter mein khareeda tha. Usko select kar. Agar "Directory" ka option maange, toh usko khali chhod de. Khali chhodne ka matlab hai WordPress seedha teri main domain (jaise merisite.com) pe install ho jayega. Agar yahan /blog ya kuch likhega, toh teri site merisite.com/blog pe banegi. Main root pe hi bithana. 2. Admin Account: Yahan tera username aur password banega. Bhai, sun meri baat. Username kabhi bhi "admin" mat rakhna. Yeh sabse bada chutiyaagiri hai jo hackers ko aam khaane ke plate mein serve karti hai. Koi aisi random cheez rakh jo tujhe yaad ho par dushman ke dimag mein na fit baithti. "therealboss" ya "deepakadmin" kuch bhi chal jayega. Password mein bina kisi sharam ke 20 characters daal, jo aalsi bhagwan bhi na tod sake. 3. Site Title: Yeh teri website ka naam hai. Abhi se chinta mat le, baad mein settings se change ho jayega. Jo marzi rakh abhi. Sab bharna ke baad "Install" ka button dabaa. Screen pe ek progress bar chalega. 30 se 60 second ke andar tera engine install ho chuka hoga. Screen pe tujhe ek login link milega—merisite.com/wp-admin. Yeh tera adda hai. Isko bookmark maar le. Takeaway: 1-click install is the real MVP. Form bharne mein oversmart mat ban, username "admin" rakh ke apni site ka gate khula chhod. Dashboard Darbaar: Yahan Raja Tu Hi Hai merisite.com/wp-admin pe gaya? Username aur password …

3. Theme Park: Site Ka Roop Dikha

Ab tak teri website bilkul us khaali plot jaisi hai jahan sirf eent (bricks) padi hain, koi building nahi. WordPress toh install ho gaya, engine bhi daal diya. Par gaadi abhi bhi bina paint aur body ke hai. Ab aate hain asli game pe—site ko dhang ka roop dena. Is chapter mein hum themes ka khel khelenge. Site ko boring se nikal kar ekdum killer banayenge. Ready? Chal shuru karte hain. Free vs Premium: Dukaan Ka Theka Bhai, WordPress ka sabse bada jadoo yahi hai ki tujhe code likhne ki zaroorat nahi. Theme ek ready-made kapde ka piece hai jo site pe pehna do, aur kaam khatam. Par market mein do tarah ke kapde milte hain—ek sasta street ka maal, doosra branded couture. Free Themes: Yeh WordPress ki apni directory pe milte hain. Astra, GeneratePress, OceanWP—yeh sab free ke milte hain. Soch samajh ke banaaye hain. Free theme ka matlab bikhari nahi hai, khas kar jab tu beginner hai. Astra ka free version itna tagda hai ki 80% log usi pe apni dukaan chalate hain. Free theme mein tujhe basic design, layout aur thodi customization mil jayegi. Premium Themes: Yeh woh hain jinke paise lagte hain. Premium tab lene ki zaroorat hai jab free wale ka support tujhe nahi chahiye, ya zyada advanced features chahiye. Premium themes mein pre-built demos aate hain—ek click kar aur poora design site pe aa jaye. Par ekdum sach bataun? Jab tak tu ek dam pro level ka client nahi pakad raha, free theme se apni pehli 5-10 sites bana. Paise zigar mein bachane se zyada dimag ka pressure kam hota hai. Takeaway: Free theme se shuruwat kar, Astra ya GeneratePress laga. Jab client paisa dega tab premium ka license khareedna, apni jeb se mat kholna. Aesthetic aur Speed: Ek Aamdani Do Karcha Yahan sab galti karte hain. Dekha hai na shaadi mein jo ladki over-the-top makeup karke aati hai, chipkati hui si lagti hai? Wahi condition heavy themes ki hoti hai. Kuch themes aate hain jinka design dekh ke hosh ud jaye. Par uske peeche 50 scripts, 10 sliders aur heavy animations chalte hain. Tera site khulta nahi, ghoomta hai. Aaj kal log ko attention span ek goldfish se bhi kam hai. Agar teri site 3 second mein load nahi hui, toh user bhaag jayega jaise local train ka last dibba chhoot gaya ho. Aesthetic vs Speed: Tujhe ek aisi ladki (theme) chahiye jo sundar bhi ho aur tere dimag ko bhi na khaye. Fast aur lightweight themes pe focus kar. Astra aur GeneratePress yahi karte hain. Yeh lightweight hote hain, coding clean rakhte hain, aur Google ko bhi pasand aate hain. Takeaway: Design sirf accha lagna chahiye, site ka engine bhi tez chalna …

4. Plugin Baazi: Site Mein Jadoo Daal

Cycle ke bina scooty aur scooty ke bina engine... aise hi chalti hai ek WordPress site bina plugins ke. Theme lag gaya? Badhiya. Site dikhti ab ekdum kadak hai. Par abhi woh ek sirf khoka hai, andar kuch kaam nahi hai raha. Customer aaya, contact karna chahta hai—kahaan se kare? Spam bots ne site ka aasmaan phaad rakha hai—kaun bachayega? Isliye ab aate hain asli game mein. Plugins. Yeh WordPress ka asli jaadu hai jo tere khoke ko ekdum solid dukaan mein badal dega. Jugaad Ka Khazana: Plugin Asal Mein Kya Hai? Soch, tune ek naya ghar liya hai. Foundation hai, deewar hain, chaat hai (yeh tera hosting aur theme hai). Ghar dikhta badhiya hai. Par bathroom mein nalka nahi laga? Kitchen mein chimney nahi hai? Main gate pe doorbell nahi? Kya naye ghar mein hi reh lega bina doorbell ke? Nahi. Tu market jayega, ek doorbell uthayega, aur ghar aake install kar lega. WordPress mein yeh doorbell, yeh chimney, yeh nalka—sab plugins hain. Plugin basically ek code ka piece hai jo teri site mein ek specific functionality add karta hai. WordPress core (jo engine hai) woh basic cheezein karta hai—content likho, dikhao. Baaki jo extra features chahiye, woh plugins ke through aate hain. Contact form chahiye? Plugin. SEO ka setup karna hai? Plugin. Site ka backup lena hai? Plugin. WordPress ka sabse bada USP yahi hai ki iska ecosystem itna bada hai, ki tujhe ek line bhi code nahi likhni padti. Kisi ne pehle hi code likh ke tere liye ready rakh diya hai. Tujhe bas 'Install' aur 'Activate' dabana hai. Desi Example: Local train ki general dabba dekha hai? Woh basic hai—logon ko aana jana hai. Par abhi soch tune usme ek fan laga diya, ek pani ki bottle latak di, aur ek seat pe cushion rakh diya. Yeh sab extras hain jo tera safar aasaan banate hain. Plugins exactly yahi karte hain. Are you getting this? Theme dikhawa hai, plugin kaam hai. Takeaway: Plugin tere site ke liye wahi hai jo mobile ke liye Play Store apps. Install kar, activate kar, kaam shuru. Dukaan Ka Gate: Contact Form Ka Setup Sabse pehla kaam jo teri site pe hone chahiye, woh hai communication. Agar customer site pe aaya aur tujhse baat karne ka rasta nahi mila, toh woh bhaag jayega. Aur WordPress by default koi contact form nahi deta. Yahan aata hai pehla asli plugin: Contact Form 7 ya WPForms. Main naye logon ko WPForms recommend karta hoon kyunki uska drag-and-drop interface ekdum beginner-friendly hai. CF7 thoda purana school hai, par free aur lightweight hai. Jo bhi choose kare, baat ek hi hai. Kaise Lagta Hai? 1. Dashboard mein jaa (left side wala menu). 2. 'Plugins' pe click …

5. Content ki Dukaan: Pages aur Posts

Site bana li, theme lag gaya, plugins ka jadoo bhi chal gaya. Par ab tak teri website ek khali dabba hai. Usme kuch nahi hai. Socho, ek dukaan di hai, paint karwa liya, lights lag gayi, par rack par maal kahan hai? Khaali shelves pe koi paise nahi dega. Ab waqt hai asli maal rack pe lagaane ka. WordPress mein content daalne ke do main raste hain: Pages aur Posts. Bani-banai website mein bas yehi cheezein user ko dikhengi. Baaki saari technical gadbad backend mein hai, customer ko sirf tera content dikhega. Toh chal, is khaali dabbe ko bharte hain. Pages: Pukka Thikaana, Kabhi Na Hilega WordPress mein 'Page' wo cheez hai jo ek baar bana ke chhod dete ho. Yeh static hota hai. Matlab iska matlab yeh nahi ki page update nahi hoga, iska matlab hai ki yeh content date ke hisaab se nahi badhta. Soch local train ki ek specific seat ka. Aaj bhi woh seat wahi hai, kal bhi wahi rahegi. Log aate jaate hain, par seat ka 'structure' aur 'purpose' fixed hai. Tere website ke 'About Us' ya 'Contact Us' ko koi nahi baith ke nahi padhta ki "Aaj 24th October hai, chalo About page padh lete hain." Log wahan jaate hain tujhe jaanne ke liye. Core Pages: Jo Dukaan Ke Bina Adhuri Hai Ek basic website banani ho toh bina kuch soche 4-5 pages hamesha banane padte hain. Inko skip karne ka sochna bhi mat. 1. Home Page: Yeh teri dukaan ka main gate hai. Yahan pe aisi cheez honi chahiye jo 3 second mein samajh aa jaye ki tu kaun hai aur kya bechta hai. Agar koi gali cricket khelne aaya aur ground pe koi nahi mila, toh woh chala jayega. Home page aisa hona chahiye ki log ruk jayein. 2. About Us: Yahan log tere baare mein padhte hain. Yahan "Hum ek passionate team hain" jaisa gyaan mat pel. Seedha bol tu karta kya hai, kab se kar raha hai, aur kyun tujhpe trust karein. Desi example le: Agar tu ek tapri pe vada pav bechta hai, toh About page pe bol "Bhai 10 saal se same chutney aur same recipe, hygiene maintain karke." Bas, kaam ho gaya. 3. Contact Us: Tujhe paise dene hain, par kahan? Contact page pe address, phone number, aur ek form daal. Map embed kar de. Make it stupidly simple. Koi itna dimaag nahi lagayega tujhe dhoondhne ke liye. 4. Services / Products: Tu kya offer karta hai? Ek dedicated page bana jahan tere services ki detail ho. Ekdam clear. Takeaway: Pages woh permanent structure hai jo teri site ka foundation banata hai. Inke bina teri website ek bhatakti aatma hai. Posts: Aaj Ka Taza Khabar, Kal Ka …

6. Drag and Drop: Elementor ki Entry

Code likhne mein apni jawani kyun kharab karein jab Elementor jaisa jugaad market mein pada hai? Pichle chapters mein humne WordPress ka engine start kiya, theme pehnaya, aur content ka stock bhi bhar diya. Ab waqt hai us dukaan ko khubsurat se sajane ka. Agar tu abhi tak HTML, CSS, aur PHP ki kachori pakad ke baitha hai, toh chhod de. Aaj hum drag and drop ki duniya mein koodenge. Elementor aisa page builder hai jahan tu mouse ka shikaari banega, aur design tere nakhre ke hisaab se banega. Bina ek line code likhe. Ready? Chal shuru karte hain. Elementor Ka Darwaza Khol Pehle basic cheez clear kar: WordPress ka default editor (Gutenberg) theek hai text likhne ke liye, par jab design karne ki baat aati hai, toh woh usme thoda bhot slow hai. Elementor aata hai game palatne. Yeh ek plugin hai (jaisa humne 'Plugin Baazi' wale chapter mein dekha tha), jo tere WordPress ke upar ek alag visual layer chadhata hai. Tu kya kar raha hai, woh same screen par live dekh sakta hai. Local train ke first class compartment jaisa feel deta hai—bheed wahi hai, par space aur comfort alag hai. Tu elements ko pakad ke jahan chahe wahan rakh sakta hai. Install aur Activate: Pehla Kadam Sidha apne WordPress Dashboard mein ghus. Left side wale menu mein 'Plugins' pe click kar, aur 'Add New' daba. Search bar mein bada sa "Elementor" likh. Pehla jo naam aayega "Elementor Website Builder", uske neeche bada sa 'Install Now' ka button hoga. Daba de. Phir 'Activate' kar. Ab tu sochega, "Bas? Itna hi?" Haan bhai, bas itna hi. Ab tera WordPress Elementor ke bina ekdin nahi reh payega, trust me. Free version mein hi itna power hai ki tu apna pura portfolio site bana sakta hai. Pro version ke baare mein baad mein sochna, abhi free wale se kaam chal. Takeaway: Plugin install karna pehle choka hai. Ab design ki real shuruwaat hoti hai. Panel Aur Canvas: Khel Shuru Jab tu Elementor activate karega, toh ek naya button banega jise "Edit with Elementor" kehte hain. Kisi bhi page ya post ko edit karne ke liye uspe click kar. Ek nayi screen khulegi—ekdum alag dashboard. Yahan do main cheezein dhyan se dekhni hain. Left side mein tera Panel hai. Yahan tere paas saare weapons rakhe hain—widgets, settings, design options. Right side tera Canvas hai. Yeh tera kora kagaz hai jahan tu design banayega. Canvas pe dekhna, ek daba hua button hoga jisme likha hoga "Add Container" ya "Plus" icon. Wahi teri entry point hai. Widgets: Tere Khilone Panel ke sabse neeche dekh, wahan tere paas ek poori list hai widgets ki. Yeh tere LEGO blocks hain. Heading, Image, Button, Text Editor, …

7. Rasta Sambhal: Menus aur Navigation

Website bana li, design thok diya, content bhi daal diya. Par ekdum soch, ek aam aadmi teri site pe aaya. Usko 'About Us' page chahiye ya koi specific article padhna hai. Agar usko ghumta-phirta nahi mila rasta, toh wo 2 second mein back button maar ke nikal jayega. Bounce rate aasmaan chhu lega, aur teri mehnat pe paani pad jayega. Navigation website ki aatma hai. Agar rasta clear nahi hoga, toh user bhatkega aur tu client ka paisa gawaayega. Aaj hum site ka GPS set karenge. Menus, widgets, aur footer—sab kuch. Fokus kar, kyunki yeh wo mechanics hai jo user ko site pe rakhti hai. Menu Ki Chori: Header Mein Rasta Kaise Banaye Header menu wo jagah hai jahan sabse pehle nazar jaati hai. Yeh teri site ka muh hai. Agar muh se gobbledygook niklega, toh koi baat nahi manega. Primary menu banana sabse basic aur zaroori skill hai. Dashboard se khel: WordPress dashboard mein ja. Left sidebar mein 'Appearance' pe hover kar, usme 'Menus' pe click kar. Ek naya screen khulega. Yeh teri navigation ki workshop hai. Menu ko naam de: Sabse upar ek box hoga 'Menu Name' likhne ke liye. Naam rakh kuch bhi—'Main Menu', 'Top Menu', ya 'Header Menu'. Create Menu pe thok. Ab tera ek khali menu ban gaya hai, jaise ek khali plot mil gayi ho ghar banane ke liye. Pages ko andar ghusa: Left side mein dekh, ek section hoga jisme tere saare Pages, Posts, ya Categories listed honge. Jo page tujhe menu mein dikhana hai (jaise Home, About Us, Contact, Blog), usko tick karke 'Add to Menu' button daba. Bam! Wo page tere menu structure mein add ho jayega. Tujhe koi code likhne ki zaroorat nahi, drag and drop se kaam ho jayega. Same jaise tiffin mein sabzi aur roti ko arrange karta hai, waise hi pages ko upar neeche ghisak kar set kar. Sub-menu bana (Drop-down): Agar tujhe 'Services' ke andar ek aur list dikhani hai, toh us page ko thoda neeche drag kar ke right side le ja. Thoda sa indent ho jayega. Yeh tera drop-down ban gaya. User jab 'Services' pe hover karega, toh niche ki list khulegi. Simple. Location set kar (Sabse zyada log yahan galti karte hain): Menu banaya, par site pe dikhayi nahi dega jab tak tu usko jagah nahi dega. Neeche scroll kar, 'Menu Settings' mein ja. Wahan 'Display location' ka option hoga. 'Primary Menu' ya 'Main Menu' jo bhi theme tera hai, usko tick karke Save Menu daba. Are you getting this? Menu banaya aur display nahi kiya, toh kya fayda? Jaise shop khadi rakhi par shutter nahi uthaya. Takeaway: Menu banana sirf pages jodne ka khel nahi hai, user ki soch ko padh ke …

8. Speed aur SEO: Site ko Rocket Bana

Site bana li, design lajawab laga diya, content bhi pel diya. Ab kya? Ab soch raha hai ki "bhai, site toh live ho gayi, par khud ke siwa koi aa hi nahi raha?" Arre, Google ko kya bata diya tujhse ki tu exist bhi karta hai? Internet ek bheed bhari local train hai. Agar tu aage se push nahi karega, toh koi tujhe platform pe chadne hi nahi dega. Yahan do cheezein teri site ki jaan hain: Speed aur SEO. Agar site dheere chalegi, toh user bhaag jayega. Agar SEO nahi hoga, toh user tak pahunchna hi nahi. Dono ko sath mein theek karna padega. Chal, engine garam karte hain. Google Ka Dil Jeet: SEO Plugin Ka Khel SEO ka matlab hai Search Engine Optimization. Simple bhasha mein: Jab koi Google pe search karega, toh Google tujhe upar dikhaye. Par Google tujhe kaise pehchane? Tere dimag ka kya hai, Google ko kaise pata chalega? Iske liye tujhe Google ko 'hints' deni padti hain. WordPress mein yeh kaam manually karna hai dimag kharab ho jayega. Isliye hum ek plugin use karte hain. Market mein do bade ustad hain: Yoast SEO aur Rank Math. Dono ka kaam ek hi hai—tujhe batana ki tere page pe kya improve karna hai. Rank Math aajkal naye khiladiyon mein trend mein hai kyunki free mein zyada features deta hai. Yoast purana aur reliable hai. Koi bhi chun le, par ek hi rakh. Dono ek sath daal ke site ka system kharab mat kar. Desi Example: Soch le tu apni nayi dukaan pe laga hai board. Par us board pe sirf "Dukaan" likha hai. Koi aayega nahi. Par agar likhe "Sharma Ji Ke Chole Bhature", toh log pehchan lenge. SEO plugin tera woh board banata hai jo Google ke map pe register hota hai. Title aur Meta Description: Pehli Mulaqat Plugin install kiya? Ab har page aur post ke niche ek box aayega. Isme do main cheezein hain: Title aur Meta Description. Title: Yeh woh line hai jo Google ke search result mein blue color mein dikhti hai. Isme main keyword hona chahiye. Agar tera page "Mumbai Street Food" ke baare mein hai, toh title mein yeh likha hona zaroori hai. "Mere Khane Ka Experience" rakh diya toh koi search nahi karega. Meta Description: Title ke neeche jo chhoti black line aati hai, woh hai meta description. Yeh tera sales pitch hai. 150-160 words mein user ko bata ki usko tere page pe kya milega. Isko catchy rakh. Focus Keyword: Plugin mein ek box hoga jisme tu apna main keyword daal. Plugin tujhe green, yellow ya red signal dega. Green matlab theek, red matlab abhi kaam baki hai. Par yeh dhyan rakh, green signal sirf hint hai. …

9. Aakhri Chunaauti: Launch aur Backup

Sab mila ke bana liya site. Theme lagaya, Elementor se design kiya, SEO aur Speed ka poora khel khel liya. Ab kya? Ab so jaye? Local train ka last local miss karne wale ki tarah beta, abhi toh sabse important rasta bacha hai. Site ko live karne se pehle ek final audit nahi kiya, toh client ya audience ke saamne tu nanga ho ke khada rahega. Yeh module tere WordPress safar ka aakhri stop hai. Yahan galti ki gunjaish zero. Chalo, is aakhri chunaauti ko tackle karte hain. Pre-Launch Audit: Bina Check Kiye Mat Nikal Gali cricket mein jab ball nahi aati, tab bhi ladka crease pe aa ke chowka marne ka sochta hai. Par professional cricket mein bina pad-pe (pitch reading) ke batting karna suicide hai. Tere site ko live karne se pehle ek strict pre-launch checklist pass karni padegi. Koi bada jhol ho gaya, toh first impression ghaati ka pani. Broken Links ki Bimari Site banate waqt tune itne pages banaye, itne buttons lagaye ki ab khud ko bhi yaad nahi ki kahan kya daala. Broken links (404 errors) wahi hote hain jaise koi tujhe address de raha ho aur wahan pahunch ke dekhe toh sirf khandar ho. User ka trust tut jaata hai, Google bhi site ki ranking girata hai. Kya karna hai? Seedha plugins library mein ja. 'Broken Link Checker' ya 'Redirection' jaisa plugin install kar. Yeh apne aap site ka scan karke batayega ki kaunsa link mara hua hai. Jo link bekaar ho gaya hai, usko fix kar ya redirect (seedha kisi valid page pe bhej de). Mobile Responsiveness ki Pehchan Aajkal log desktop pe site dekhne se zyada phone pe dekhte hain. Local train mein chadh ke, vada pav khaate hue, ya toilet mein baith ke log phone se hi internet chalate hain. Agar teri site phone pe khichdi ban ke dikhegi, toh user bhaag jayega. Kya karna hai?
